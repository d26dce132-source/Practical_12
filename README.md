# 🎓 StudentHub Portal

## Project Description

StudentHub Portal is a responsive student management website developed using HTML and CSS.

The portal provides a modern interface where students can access academic information such as:

- Student Login
- Student Registration
- Dashboard
- Courses
- Assignments
- Attendance
- Results
- Student Profile
- Contact Page

---

## Technologies Used

- HTML5
- CSS3
